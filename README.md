Bank Management System
A simple console-based Bank Management System built using Java. This project demonstrates fundamental Object-Oriented Programming (OOP) concepts and basic banking operations.
Features
Create a bank account
Deposit money
Withdraw money
Check account balance
View account details
Input validation for transactions
